Periksa nomor telepon

Masukkan nomor dalam format apa pun. Pemeriksaan membaca awalan nomor di browser Anda untuk menunjukkan negara, operator asal, dan apakah panjangnya wajar. Cara ini tidak bisa memastikan nomor aktif atau menemukan pemiliknya.

Validasi dan normalisasi memakai libphonenumber-js (metadata libphonenumber Google) yang diproses lokal di browser Anda. Nomor tidak dikirim ke mana pun.

Operator asal menunjukkan penerbit awalan nomor. Nomor yang sudah dipindahkan ke operator lain lewat portabilitas nomor tidak bisa dikenali dari awalan. Metadata bersumber dari libphonenumber-js (dimuat via CDN jsDelivr) dan peta prefix operator/kode area Indonesia bawaan halaman ini.

Privasi

Jejak berjalan di browser Anda. Situs ini tidak punya server untuk menyimpan data, dan tidak memakai cookie atau penyimpanan lokal.

Dua layanan luar dipakai: ipapi.co untuk mencari lokasi alamat IP (dengan ipwho.is dan ipify sebagai cadangan), dan OpenStreetMap untuk menampilkan peta. Keduanya menerima alamat IP Anda saat dimuat, seperti situs web pada umumnya.

Lokasi GPS dan nomor telepon tidak dikirim ke mana pun oleh halaman ini. Satu pengecualian: peta OpenStreetMap menerima koordinat yang sedang ditampilkan, karena koordinat itu menjadi bagian dari alamat petanya.
